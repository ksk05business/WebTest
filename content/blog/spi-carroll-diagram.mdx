## SPIの集合でベン図を書くと時間切れになる理由

集合の問題が出た瞬間、反射的に丸を2つ描いてベン図を書き始めていませんか？重なり合う部分に数字を書き込んでいくうちに、どこに何を書いたか分からなくなりパニックになる——これは非常によくあるパターンです。

</ChatBubble>

</ChatBubble>

キャロル表は、2つの属性を縦軸・横軸に取り、マスに人数を当てはめていくだけの表です。丸を重ねる必要がなく、足し算・引き算だけで機械的に解けます。

## キャロル表の書き方（雛形）

まず、キャロル表の基本形を確認しましょう。縦軸・横軸それぞれの属性と、行・列・全体の「合計」欄を持つ3×3の表になります。

| ＼ | 属性B：あり | 属性B：なし | 合計 |
|---|---|---|---|
| 属性A：あり |  |  |  |
| 属性A：なし |  |  |  |
| 合計 |  |  |  |

空いている4マス（データのマス）と、それを裏付ける3つの「合計」（行合計・列合計・全体合計）で構成されています。この形を覚えておくだけで、集合の問題は一気に整理しやすくなります。

## 例題で実践してみよう

次のような問題で、実際にキャロル表を使ってみましょう。

> ある就活セミナーに、学生100人が参加した。参加者について次のことがわかっている。
>
> - 参加者の合計：100人
> - 男子の人数：60人
> - 理系の人数：40人
> - 理系の男子の人数：20人
>
> このとき、文系の女子は何人か。

<PointBox label="ここがポイント">
  条件文を読んだ瞬間に表を描き始める必要はありません。まず「合計」から埋め、既に分かっている交差データを1マスだけ埋めれば、残りは引き算だけで自動的に求まります。
</PointBox>

## 解き方のステップ：「合計」から埋めて引き算する

### ステップ1：分かっている「合計」を先に埋める

全体の合計は100人、男子は60人なので女子は`100－60＝40人`。理系は40人なので文系は`100－40＝60人`です。ここまでで「合計」の行と列がすべて埋まります。

| ＼ | 理系 | 文系 | 合計 |
|---|---|---|---|
| 男子 |  |  | 60 |
| 女子 |  |  | 40 |
| 合計 | 40 | 60 | 100 |

### ステップ2：分かっている交差データを1マスだけ埋める

「理系の男子は20人」という条件を、男子×理系のマスにそのまま書き込みます。

| ＼ | 理系 | 文系 | 合計 |
|---|---|---|---|
| 男子 | 20 |  | 60 |
| 女子 |  |  | 40 |
| 合計 | 40 | 60 | 100 |

### ステップ3：行・列の合計から引き算で残りを埋める

あとはすべて引き算です。

男子の行合計（60）から男子×理系（20）を引くと、男子×文系＝`60－20＝40人`。

理系の列合計（40）から男子×理系（20）を引くと、女子×理系＝`40－20＝20人`。

女子の行合計（40）から女子×理系（20）を引くと、女子×文系（＝文系の女子）＝`40－20＝20人`。

| ＼ | 理系 | 文系 | 合計 |
|---|---|---|---|
| 男子 | 20 | 40 | 60 |
| 女子 | 20 | 20 | 40 |
| 合計 | 40 | 60 | 100 |

**答え：文系の女子は20人**です。念のため、文系の列合計（60）から男子×文系（40）を引いても`60－40＝20人`となり、一致することを確認できます（この相互チェックができるのもキャロル表の強みです）。

## 解き方が分かったら、忘れる前に演習しよう

キャロル表の書き方自体はシンプルですが、「合計から先に埋める」という手順は、実際に何度か手を動かして初めて体に馴染みます。逆に、ここで解き方だけ理解して満足してしまうと、数日後にはまた振り出しに戻ってしまいます。
